# Xogtus-App 🚀

A React Native mobile app built with **Expo** and **NativeWind (TailwindCSS for React Native)**.

---

## 📲 Installation & Run

### 1. Clone the Repository
```bash
git clone https://github.com/YourUsername/Xogtus-App.git
cd Xogtus-App
```

### 2. Install NPM Packages
```bash
npm install
```

### 3. Start the Expo Development Server
```bash
npx expo start
```

This will open the Expo Developer Tools in your browser and show a QR code in the terminal.

### 4. Run on Your Device
- Install the **Expo Go** app from Google Play (Android) or App Store (iOS).
- Open **Expo Go** → Scan the QR code → The app will launch on your phone.

---

✅ That’s it! After cloning, installing, and starting with `npx expo start`, you can run **Xogtus-App** directly on your mobile device using Expo Go.
